## 📌 Descrição do Projeto

Este projeto consiste no desenvolvimento de uma landing page funcional destinada à apresentação de um portfólio pessoal. O objetivo é consolidar, em um único espaço digital, informações relacionadas à formação, habilidades técnicas e comportamentais, bem como projetos desenvolvidos ao longo do curso.

A página foi desenvolvida utilizando HTML, CSS e JavaScript, aplicando conceitos fundamentais de estruturação semântica, estilização, responsividade e manipulação básica do DOM. O projeto busca demonstrar organização, clareza na codificação e aplicação prática dos conhecimentos adquiridos durante o curso.

---

## 🧱 Estrutura da Página

A landing page está organizada nas seguintes seções:

- Apresentação (nome do estudante e descrição profissional)
- Sobre Mim
- Habilidades Técnicas
- Habilidades Comportamentais
- Projetos Desenvolvidos
- Contato

Cada seção foi estruturada de forma clara e objetiva, permitindo fácil navegação e leitura das informações.

---

## 💻 Tecnologias Utilizadas

- HTML5 (estrutura da página)
- CSS3 (estilização, layout com Flexbox e Grid)
- JavaScript (navegação com scroll suave entre seções)

## ▶️ Instruções para Execução

1. Extrair o arquivo compactado (.zip ou .rar).
2. Abrir o arquivo `index.html` em qualquer navegador atualizado.
3. Navegar pelas seções utilizando os botões do menu.

Não é necessário instalar dependências adicionais.
